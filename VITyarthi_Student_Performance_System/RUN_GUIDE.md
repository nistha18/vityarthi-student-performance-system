# VITyarthi Submission & Demo Guide

## 1. Requirements
- Python 3.9+ recommended
- No external Python packages required to run the application

## 2. Run
From the project root:

```bash
cd src
python main.py
```

## 3. Optional demo data
From the project root:

```bash
cd src
python demo_data.py
python main.py
```

## 4. Run tests
From the project root:

```bash
python -m unittest discover -s tests -v
```

## 5. GitHub
Create a GitHub repository and upload the complete project folder.

Suggested repository name:
`vityarthi-student-performance-system`

Suggested commits:
1. `Initial project structure`
2. `Add SQLite database and CRUD modules`
3. `Add analytics and reporting`
4. `Add unit tests and documentation`
5. `Finalize VITyarthi report`
