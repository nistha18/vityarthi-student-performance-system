# Project Statement

## Project Title
Student Performance & Attendance Management System

## Problem Statement
Manual management of student marks and attendance can require repeated calculations and can make it difficult to obtain a consolidated view of academic performance. The proposed system provides a modular Python solution for maintaining student records, subject-wise marks, attendance and performance reports.

## Scope
The project covers student registration, academic marks entry, attendance entry, validation, SQLite storage and performance reporting. It is intended as an academic demonstration project and is not designed as a production college ERP.

## Target Users
- Students
- Faculty members
- Academic project evaluators

## High-Level Features
- Add, view and delete student records.
- Add and view subject-wise marks.
- Add and view attendance.
- Calculate average marks.
- Calculate attendance percentage.
- Generate individual performance reports.
- Generate a class performance report.
- Validate user input and handle common errors.
